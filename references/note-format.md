# 学习笔记格式规范

## 文件命名

两位数字序号 + "." + 标题 + ".md"
例如：`01.认识权谋的黑暗艺术.md`

## 文章结构

每篇文章按三层框架组织，用小标题分隔：

### 问题本身
- 是什么
- 为什么会出现这个问题
- 不同的分支和可能情况

### 解决方案
- 怎么解决
- 为什么用这种方式
- 背后的设计决策
- 边界情况

### 更大背景
- 为什么重要
- 会影响哪些地方
- 会带来什么后果

## 评分字段（YAML frontmatter）

```yaml
---
topic: 事大惊人术
domain: 权谋
feynman: green
quiz_score: 3/4
mastery: 待复习
last_reviewed: 2026-06-09
next_review: 2026-06-11
---
```

## 结尾要求

每篇文章结尾必须包含 [诊断问题] 或 [练习任务]。
